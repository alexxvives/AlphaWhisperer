Privacy Policy

BrainAI · Last updated 6 September 2026

BrainAI is a personal, self-hosted home automation project operated solely by Alexandre Vives (alexxvives@gmail.com). It is not a commercial service and has no other users.

What data is accessed

With the owner’s explicit Google account consent, BrainAI may read:

  • Google Calendar events (daily calendar briefing)
  • Gmail unread mail / metadata (daily email digest)

How data is used

Data is processed on the owner’s home server to generate short daily summaries. Those summaries are sent only to the owner’s Telegram chat. Data is not sold, shared with third parties, or used for advertising.

Storage

Temporary processing happens on the home server. Google account tokens are stored in the owner’s self-hosted automation software (n8n). There is no public user database.
